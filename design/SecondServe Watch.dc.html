La saisie sur le court

Le geste de base est constant : moitié gauche = point pour toi, moitié droite = point adverse. Zones de 50% chacune, imprécises exprès (bras levé, plein soleil, mains moites). La correction retenue : deux boutons permanents sous le score — ↩ annuler le dernier point ou ⇄ le basculer vers l'autre joueur.
