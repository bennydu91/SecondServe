### DL-008 · Suggestions de tournois → V2

### DL-009 · Succès = rétention + progression qualitative
**Décision :** Les métriques de succès V1 sont centrées sur la rétention en match (≥ 80% des matchs) et l'engagement hors match, complétées par une auto-évaluation qualitative mensuelle.
**Contexte :** Question PRD session 2026-06-08 — montée de classement jugée trop difficile à quantifier sur une courte période.
**Statut :** Confirmé.

---

### DL-010 · Suivi score au niveau des points individuels
**Décision :** Le suivi de score Pixel Watch inclut les points individuels (15-0, 30-15, Avantage) + jeux + sets.
**Contexte :** Décision PRD session 2026-06-08 — granularité nécessaire pour l'analyse post-match.
**Statut :** Confirmé.

---

### DL-011 · Format de match configurable au démarrage
**Décision :** Le format du match (nombre de sets, règle du 3e set : avantage / super tie-break / set raccourci) est configuré obligatoirement au démarrage de chaque Session Match.
**Contexte :** Super tie-break fréquent dans les formats FFT — résolution OQ-2.
**Statut :** Confirmé.

---

### DL-012 · Analyse individuelle post-match + synthèse multi-matchs
**Décision :** Deux niveaux d'analyse IA distincts — (1) analyse individuelle générée à la clôture de chaque match, (2) synthèse transversale déclenchée après 3 matchs.
**Contexte :** Décision PRD session 2026-06-08 — résolution OQ-4.
**Statut :** Confirmé.

---

### DL-013 · Consignes du coach humain — structure semi-guidée
**Décision :** 3 champs structurés : "Axe de travail principal", "Axe de travail secondaire", "Points à éviter".
**Contexte :** Décision PRD session 2026-06-08 — résolution OQ-5. Meilleure qualité de prompt IA vs texte libre.
**Statut :** Confirmé.

**Contexte :** Cas d'usage en match = téléphone dans le sac à < 10m. Résolution OQ-6.
